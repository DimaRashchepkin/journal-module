# journal-module
МОДУЛЬ ЖУРНАЛИРОВАНИЯ:
Ведет журнал своей работы
Данные для чтения доступны через procfs
Команды передаются через sysfs

ОТСЛЕЖИВАЕМЫЕ ПАРАМЕТРЫ:
- активная конфигурация (defconfig/config)
- количество обращений к файлу procfs
- время последнего обращения
- статус (enabled/disabled)
- время последнего сброса

ТЕХНИЧЕСКИЕ КОМАНДЫ:
- 2 = reset
- 1 = enable
- 0 = disable
